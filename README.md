# ONGI 프로토타입

AI 화분과 연동되는 식물 돌봄 앱 **ONGI**의 인터랙티브 프로토타입입니다.
화분은 윗면의 파동 무늬와 빛으로 마음을 표현하고, 처음에는 식물을 돌봐 달라고 요청하다가
매일의 문답이 쌓이면 점점 사용자를 이해하게 됩니다. 그러면 사용자를 닮은 새 식물 캐릭터가 찾아옵니다.

## 시연 방법

페이지에 들어가면 왼쪽에 휴대폰 화면, 오른쪽에 **프로토타입 컨트롤**이 있습니다.
휴대폰 화면은 실제 앱처럼 눌러서 쓰고, 컨트롤로는 실제 화분에서 들어오는 신호를 흉내 냅니다.

1. 설문 3개에 답하고 식물을 고른 뒤 프로필을 만들면 홈 정원에 식물이 심어집니다.
2. 화분이 원하는 돌봄이 **오늘의 퀘스트**로 나오고, 화분 윗면이 그에 맞는 파동으로 움직입니다.
3. 컨트롤의 **실제 화분 돌보기**로 돌봄을 하면 퀘스트가 완료되고 아이템과 경험치를 받습니다.
4. **오늘의 질문**에 답하고 **다음 날로**를 눌러 문답을 3번 쌓으면 새 식물 캐릭터가 찾아옵니다.

## 화분의 파동 (리플 인터랙션)

움직임은 다섯 가지로 같고, 화분의 이해도 레벨에 따라 의미와 빛만 달라집니다.

| 움직임 | Level 1 상태 (백색광) | Level 2 감정 | Level 3 메시지 (따뜻한 노란빛) |
|---|---|---|---|
| 01 잔잔한 낮은 물결 | 갈증 | 감사 | 지금 상태를 존중함 |
| 02 중심에서 바깥으로 퍼지는 물결 | 햇빛 부족 | 안도 | 진정시키려 함 |
| 03 불규칙한 다중 움직임 | 온도와 습도 불편 | 신남 | 기쁨을 함께 나눔 |
| 04 안쪽에서 바깥쪽으로 천천히 확장 | 영양 부족 | 만족 | (없음) |
| 05 회전하는 물결 | 환기 필요 | 애정 | 응원함 |

- **레벨 (자동):** 캐릭터가 오기 전 Level 1, 캐릭터가 오면 Level 2, 캐릭터가 '어린 잎'으로 자라면 Level 3
- 레벨이 올라가도 돌봄이 필요할 때는 Level 1의 의미와 백색광으로 다시 알립니다.
- Level 3에서는 오늘 고른 마음에 맞춰 반응합니다. 평온은 존중, 놀람과 화남은 진정, 고민은 응원, 슬픔은 기쁨을 나눔.

## 프로토타입 컨트롤

- **실제 화분 돌보기:** 물, 햇빛, 온습도, 영양제, 환기. 점이 찍힌 버튼이 지금 화분이 원하는 돌봄입니다.
- **새 식물 캐릭터:** 마음 기록 비율로 정해지는 등장 확률과 직접 선택
- **이해도 레벨, 파동 직접 재생, 시간대(아침, 저녁, 밤)**
- **진행:** 다음 날로, 새 식물 등장, 경험치와 포인트 추가, 화면 바로 가기, 처음부터 다시

진행 상태는 브라우저에 저장되므로, 처음부터 보려면 컨트롤 맨 아래 **처음부터 다시**를 누르세요.

## 파일 구성

- `index.html`, `styles.css`, `app.js`: 프로토타입 본체 (빌드 과정 없음)
- `pot-geo.js`: Figma 화분 윗면 링의 실제 윤곽 데이터
- `assets/`: Figma에서 가져온 그림과 아이콘, 식물 일러스트
- `tools/gen_plants.py`: 식물 종류별 일러스트 생성기 (`python3 tools/gen_plants.py`)

## 로고 바꾸기

| 위치 | 파일 | 규격 |
|---|---|---|
| 앱 상단 왼쪽 로고 | `assets/logo-header.svg` | SVG 권장, 높이 23px로 표시(가로 최대 160px). 여백 없이 로고에 맞춰 자른 가로형. PNG면 높이 69px(3배) |
| 브라우저 탭 아이콘 | `assets/favicon.svg` | 정사각형(1:1) SVG, 투명 배경, 32px에서도 알아볼 수 있는 심볼 |

`assets/logo-header.svg`가 없으면 임시 로고(심볼 + 글자)가 대신 보입니다.
